# Go Mihyeon — HR Portfolio (GitHub Pages)

HTML, CSS, JavaScript만으로 만든 정적 사이트입니다. 별도의 빌드나 서버가 필요하지 않습니다.

## 미리 보기

`index.html`을 브라우저에서 열어 확인할 수 있습니다. 일부 기능(클립보드 복사)은 HTTPS로 배포한 후에 정상 작동합니다.

## GitHub Pages 배포 방법

1. GitHub에서 새 **Public** 리포지토리를 만듭니다. 예: `hr-portfolio`.
2. 이 폴더의 `index.html`, `styles.css`, `script.js`, `README.md`, `assets/`를 리포지토리 **최상위 경로**에 업로드합니다. ZIP 그대로 업로드하지 말고 압축을 푼 파일을 올리세요.
3. 리포지토리 **Settings → Pages**에서 **Build and deployment → Deploy from a branch**를 선택합니다.
4. Branch를 `main`, 폴더를 `/ (root)`로 선택한 뒤 Save를 누릅니다.
5. 배포 완료 후 `https://깃허브아이디.github.io/hr-portfolio/` 주소에서 확인합니다.

GitHub Pages가 계정·리포지토리 설정에 따라 활성화되지 않을 수 있습니다. 사이트를 공개적으로 배포할 때는 사내 자료의 권리와 공개 가능 여부를 확인해 주세요.

## 수정 가이드

- **소개/경력/전체 구성**: `index.html`에서 수정
- **색상·디자인·반응형**: `styles.css`의 `:root` 변수와 각 섹션 수정
- **프로젝트 상세 내용**: `script.js` 상단 `projects` 객체 수정
- **영상·프로젝트 앱 URL 연결**: `script.js`의 `video`, `advent` 등 프로젝트 항목에 `url: 'https://...'` 입력. 카드 클릭 후 상세창에 결과물 보기 링크가 나타납니다.
- **실제 프로젝트 이미지**: `assets/`에 이미지를 넣은 후 HTML 프로젝트 카드의 `.project-visual` 영역을 이미지 요소로 교체하거나 배경 이미지를 지정
- **이력서 PDF 링크**: 파일을 `assets/resume.pdf`로 넣고 공개 전 개인정보를 검토한 뒤 원하는 위치에 `<a href="assets/resume.pdf" download>이력서 다운로드</a>` 추가
- **사용자 지정 도메인**: GitHub Pages 설정에서 연결 가능

## 사실 확인 및 배포 전 점검

- 사업장 수, 인원 수, 수상 내역, 기여도, 경력기간, 자동화 효과 등의 수치를 재확인하세요.
- 2026년 12월 어드벤트 캘린더는 **기획 중**으로 작성했습니다. 행사 완료 후 운영 결과를 반영하세요.
- 30주년 홍보영상은 개인 제작 기여도 100%이지만 수상은 **팀 단위**였으므로 그 차이를 분리했습니다.
- 사내 영상·브랜드 로고·음원·사진, 인사·급여 데이터는 회사의 외부 공개 승인을 받은 경우에만 업로드하세요.
- 개인 이메일, 휴대전화, 이력서 파일, 실제 영상 링크는 아직 넣지 않았습니다.
- AI 구독 관리 건수와 비용 증가는 **구독 규모 변화**이며 비용 절감이나 AI 프로젝트의 직접적인 성과로 표현하지 않았습니다.
- CSS/JS는 외부 CDN이나 프레임워크를 사용하지 않아 GitHub Pages에서 별도 설정 없이 동작합니다.
